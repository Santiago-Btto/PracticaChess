# Cburnett chess pieces

`b*.svg` y `w*.svg` son el set de piezas **Cburnett**, atribuido a Colin M. L.
Burnett. Las imágenes `*.png` son conversiones locales de esos SVG para el
renderizado confiable de Kivy en Android.

- Fuente: https://lichess1.org/assets/piece/cburnett/
- Licencia: [CC BY-SA 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/)

Estas piezas no son recursos ni una copia del set de Chess.com.
